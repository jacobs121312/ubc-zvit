# Звіт по витратах · УБЦ

Сторінка подання витрат і авансів для лідерів служінь.

- Вхід — «Увійти через Google» (лише пошта й ім'я).
- Дані й чеки зберігаються в Google Таблицях і на Google Диску церкви через окремий сервер (Google Apps Script).
- У цьому репозиторії немає жодних даних, паролів чи ключів — лише сама сторінка.

## Зміни в index.html

На сторінці діє Content-Security-Policy з гешами вбудованих скриптів. Після будь-якої зміни
скриптів в `index.html` оновіть її, інакше браузер заблокує скрипт:

```
python3 scripts/update-csp.py
```
